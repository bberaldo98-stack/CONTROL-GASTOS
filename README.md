# Mis Finanzas

Archivos incluidos:
- index.html
- manifest.json
- icon-512.png
- apple-touch-icon.png

Para GitHub Pages:
1. Sube estos 4 archivos a la raíz del repositorio.
2. Settings → Pages.
3. Source: Deploy from a branch.
4. Branch: main.
5. Folder: /(root).
6. Save.

No necesitas servidor ni base de datos. Los movimientos se guardan localmente en el dispositivo mediante localStorage.
